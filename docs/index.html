carp-input

Action-based input for Carp.

(load "git@github.com:carpentry-org/carp-input@master")
  • InputManager — bindings, action state, axes
  • GLFWBackend — feeds the manager from GLFW events

Game logic asks whether "MoveForward" is active, not whether W is down. A binding maps hardware (keys, mouse buttons, joystick axes) to a named action, and rebinding a control means changing the binding rather than hunting through gameplay code for key codes.

(let-do [im (InputManager.new)]
  (InputManager.bind! &im "MoveForward" (Key.w))
  (InputManager.bind! &im "MoveForward" (Key.up))
  (when (InputManager.active? &im "MoveForward")
    (move-player)))

InputManager on its own has no dependency on a window library; loading input.carp alone gets you the manager without GLFW. The backend is the part that needs GLFW, and pulls in carp's own GLFW.carp, which wants glfw3 available to pkg-config.
